# EXAMEN 2024

### ejercicio 1.

```cs
cat listado.txt | wc -l
```

El <mark><u>***Usuario***</u></mark> introduce la línea de comandos en la terminal. Esta es leída e interpretada por el ***Shell***, que es una <mark><u>***utilidad del S.O***</u></mark>, encargada de procesar las órdenes recibidas.
<br>

Para llevar a cabo la ejecución, el Shell solicita servicios al <mark><u>***Núcleo del S.O***</u></mark> mediantes llamadas al sistema definidas en la <mark><u>***interfaz de aplicación (API)***</u></mark>. A partir de este momento, intervienen diversos componentes del núcleo:

- El <mark><u>***Gestor de procesos***</u></mark> se encarga de crear, planificar y coordinar la ejecución concurrente de los procesos `cat` y `wc`.

- El <mark><u>***Gestor de memoria***</u></mark> reserva y asigna los espacios de memoria principal necesarios para el código y datos de dichos procesos

- El <mark><u>***Gestor de archivos***</u></mark> gestiona el acceso al fichero `listado.txt` en el sistema de archivos y crea el canal de comunicación (tubería / pipe) entre ambos comandos.

- Los <mark><u>***Manejadores de dispositivos (drivers)***</u></mark> interactúan directamente con los periféricos para leer el fichero del almacenamiento y mostrar el resultado por pantalla.

Finalmente, todas estas operaciones terminan ejecutándose físicamente sobre el <mark><u>***Hardware***</u></mark> del sistema (CPU, memoria RAM y controladores de dispositivos).
